# B 组：motion-derived command 首轮试验

用户授权先试B，其余实验组和原多种子守护保持停止。

唯一训练干预：每8秒更新的command改为三段Dinosaur动作的1秒root速度平均，FW/BW/SW等权，按原始速度范围过滤候选且不裁剪，不应用0.2死区。RSI仍独立于command，AMP正样本、五个关键点、速度通道、奖励系数及原版每轮预算不变。BW/FW/SW候选保留952/845/1163（各1438个原始候选），排除率约33.8%/41.2%/19.1%；完整元数据写入environment_resume.json。SW有效候选中约24.3%的平面速度低于0.2。

为尽可能只改变command，首轮直接从A的`original_budget_calibration_mlp/ckpt_000500.pt`复制全部网络、优化器和随机状态；该检查点Actor尚未更新，Critic尚未训练。这次不额外重新初始化D/Critic（与先前四组全面重跑的初步方案不同），便于直接对照已有A相同检查点。fork参数只允许在校准边界改变command_profile；训练后续恢复仍严格检查配置。

训练从iteration501到10500，共10000次Actor更新轮次（若数值保护跳过会保留计数），不是接着200k已形成策略微调。检查点1500/4000/10500对应1000/3500/10000次Actor更新轮次；额外在3500/10000与已有A精确对齐3000/9500次Actor更新轮次。训练过程不因评估重启；评估进程旁路读取原子检查点。

每个里程碑执行原七指令32实例20秒评估，以及近专家速度点[.4,0,0]、[-.27,0,0]、[.08,-.22,0]、[.08,-.14,0]。最后一个点为源死区之外的慢速诊断点，不能称为A/B共同训练支持域。原七指令里的高速侧移等仍属于B可能未覆盖的外推控制检查。A/B使用相同评估初态种子协议v2，历史A相同budget检查点会重新评估，不直接混用旧协议数字。

录制前进、后退、y−侧移，保留每组第1实例的固定选择规则。单个种子、10k轮次只是筛选，不足以证明风格改善。判别器分数不得跨组直接当风格排名；后续应使用固定专家归一化的姿态分布指标及相同速度/方向视频检查。

运行配置：`configs/blinkamp/style_B.json`。运行器：`tools/run_amp_command_trial.py`。产物：`logs/blinkamp/style_ablation_B_seed0/`；不会启动A/C/D，也不会自动延长到200k。
