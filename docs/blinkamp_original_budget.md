# 原版学习预算重跑

本实验恢复 `scripts/presets.sh main` 与 `logs/reproduce_local/s0/args.json` 的每轮采样及优化预算，Dinosaur 奖励、motion、采样、root 坐标和已确认的初始化/reset 隔离保持不变。

| 项目 | 本次配置（与原版 main 相同） |
|---|---|
| 环境 / 回放 | 4096 / 1000 向量步，共 4,096,000 条转移 |
| 采集 | UTD=0.4，每轮交替采 2、3 个向量步，平均 10,240 条真实转移 |
| 策略预算 | batch 2048，horizon 32，即 65,536 个想象时间位置；每轮优化一次 |
| WM 预算 | batch 2048，window 8，每轮更新 5 次，即 81,920 个监督时间位置 |
| Critic 预算 | 每轮 5 epochs × 4 shuffled minibatches，共 20 次优化 |
| 历史 / 网络 | 10 帧，Actor 隐藏层 2048/1024/512/256，WM 1024×3 |
| 优化器 | Actor/WM 复用原版 MuonAdam；Critic Adam |
| 学习率 | 基础 4e-4，原版余弦衰减至 3%（250k 周期）；Actor 初始倍率 4 |
| 其他 | 原版 gamma=.99、lambda=.95、EMA=.995、探索=.1、范数裁剪1、Actor逐元素裁剪.1、bf16 MLP |

可复现配置为 `configs/blinkamp/original_budget.json`。为在 16 GB GPU 上保留完整回放容量，回放放主存。先验证了 512 子批梯度累积的等价性，随后完整 2048 batch 真实更新也通过显存验收；正式策略训练直接使用完整 batch，不做梯度累积。配置仍支持子批执行以备需要。Critic 仍按完整 65,536 个状态构建固定目标，每 epoch 重新打乱并分成 4 批。测试验证了小规模确定性场景下分批/不分批 Actor 参数更新一致，且 Actor 仅更新1次、Critic更新20次。

明确的任务适配和差异：

- 原版 Actor 接收未来参考目标并带参考动作残差；本任务仍是指令条件 AMP，不引入这两项。保留指令编码器；恢复 Actor 主网络隐藏层宽度。
- 原版根据模仿归一化回报达到 .75 或最迟 iteration 1400 触发 Actor LR 倍率衰减。AMP 没有同语义模仿回报，本次采用原版 iteration 1400 的截止触发，之后300 iteration将倍率4降到1；不把 AMP 总奖励冒充原版指标。
- AMP 判别器与力矩头为额外模块，原版没有对应预算；保持判别器每轮2次、每类512窗口、LR1e-4，力矩头随WM每轮5次监督更新。
- 新任务需要力矩预测监督，保留前500 iteration冻结策略校准。3500 iteration里程碑因此包含500校准和3000 Actor更新，不能描述为与原版3500 Actor更新完全相同。
- 所有模型和归一化统计从头初始化，不再导入旧任务已经冻结的WM统计。原版2e8冻结机制本身仍保留。
- 当前使用局部 torch.compile 和 bf16，尚未为 AMP 路径移植原版完整 CUDA Graph。学习预算相同不代表每秒 iteration 相同。

实验流程：先500 iteration校准验收（力矩头留出误差<.1且优于零预测，无非有限更新，策略未更新），然后恢复至3500进行七指令真实仿真评估和视频导出；之后继续至此前要求的200k上限，并用第二随机种子重复。恢复会重填回放并重置仿真，不是位级连续恢复。所有阶段及种子独立记录配置、检查点和日志。原版3500仅作为首个对照里程碑，200k是本任务先前要求的扩展预算。

旧实验保留：seed0已完成200k，seed1重跑切换时保留最新30k检查点和全部曲线，旧队列已停止。新运行使用独立目录，不覆盖旧产物。

验收：原有30项回归检查通过；新增预算/UTD/LR契约及主存回放/梯度累积等价性/20次Critic更新检查。4096环境、完整预算、冷模型已完成真实更新冒烟测试，无非有限值，并成功保存检查点。完整配置试跑的吞吐约1.5–1.6 it/s（两轮未编译试跑，非独占GPU）（不含长程收敛保证）。
